# 项目计划书：边缘 AI 双芯感知节点

## 背景与目标
用户为智能电表固件工程师（MCU 方向，刚入职）。希望不浪费 MCU 经验地学习 Linux 开发，锻炼 AI 辅助开发与边缘计算能力，做出可求职展示的作品。

## 约束（用户确认，2026-09-09）
- 时间：每天 1-1.5h 碎片 + 大小周休息日半天（3-4h）
- Linux 基础：会用常用命令、跑过 ROS；未系统用过 vim/git/交叉编译；用 VS Code 写过代码
- 方向偏好：先底层打牢，再逐步叠加 AI（两步走）
- 目的：学得扎实 + 能变成求职作品（两者都要）
- 硬件：RK3566 开发板已有；ESP32 **手头已有**；可再投几百元采购外设
- 环境：全程由 GitHub Copilot（Agent）协作，作为"AI 辅助开发"练习场

## 主项目（已定稿）
**「边缘 AI 双芯感知节点」**
- 前端：ESP32（默认 ESP-IDF 框架；求快可切 Arduino）
- 主控：RK3566 Linux（字符驱动/设备树/UART/多线程应用）
- AI：NPU(RKNN)，USB 摄像头视觉目标检测（YOLO→.rknn）
- 闭环：NPU 推理结果 → UART → ESP32 驱动执行（报警/记录/跟随）

## 架构
```
ESP32(采集/控制) ──UART(自定义帧协议,CRC)──► RK3566(驱动+应用+协议解析) ──RKNN──► NPU 推理
       ▲                                                                    │
       └──────────────── 执行指令 ◄─────────────────────────────────────────┘
```
