## 主项目（已定稿）
**「边缘 AI 双芯感知节点」**

### 具体场景：区域智能安防监测（2026-09-10 定稿）
> 低功耗 MCU 常驻侦测 + Linux NPU 按需重推理

**演示剧本**：无人时 ESP32 靠 PIR 常驻侦测（低功耗）→ 有人接近则 UART 唤醒 RK3566 → 摄像头采集 + NPU 推理确认 → 下发指令 → ESP32 蜂鸣器报警 + LED 红闪 + 舵机云台转向 → 人离开后复位，事件落盘可回放。

**为什么是这个场景**：双芯分工有硬道理（功耗 vs 算力分层，不是为用两块芯片而用）；闭环完整（感知→推理→决策→执行）；指标可量化（延迟/帧率/准确率）；硬件成本 < 150 元；演示直观。

### 技术栈
- 前端：ESP32（ESP-IDF v5.x + FreeRTOS）—— PIR/温湿度采集，蜂鸣器/LED/舵机/OLED 执行
- 主控：RK3566 Linux（字符驱动/设备树/UART/多线程 C++ 应用）
- AI：NPU(RKNN)，USB UVC 摄像头，YOLOv8n → INT8 → `.rknn`
- 协议：自定义二进制帧（SOF/LEN/CMD/SEQ/PAYLOAD/CRC16），115200 8N1

> 📌 **功能需求（FR）、量化指标、协议定义、BOM、风险登记册见 [`SPEC.md`](SPEC.md)**

## 架构
```
ESP32(采集/控制) ──UART(自定义帧协议,CRC)──► RK3566(驱动+应用+协议解析) ──RKNN──► NPU 推理
       ▲                                                                    │
       └──────────────── 执行指令 ◄─────────────────────────────────────────┘
```
